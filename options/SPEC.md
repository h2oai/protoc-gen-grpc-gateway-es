# Option descriptors

## Responsibility

Generated `@bufbuild/protobuf` message classes for the non-scalar annotations the plugin reads. protobuf-es can only `getOption` an extension whose message class is already generated.

Regenerated by `bun run generateOptions` (`options/buf.gen.yaml`, `target=ts`) from `buf.build/googleapis/googleapis`, `buf.build/grpc-ecosystem/grpc-gateway`, and `buf.build/protocolbuffers/wellknowntypes`. Output lands in `options/gen/` and is committed.

## Boundary

- Allowed: nothing in this repo. The tree is generated.
- Forbidden: hand-editing `options/gen/**`. Change the inputs and regenerate. Forbidden: importing plugin source.

## What is actually read

Only four descriptors are on the generation path:

- `google.api.http` — RPC method, path, body
- `google.api.field_behavior` — required / output-only
- `google.api.resource` — resource-name patterns
- `protoc-gen-openapiv2` `openapiv2_schema` — JSON-schema `required`

The rest of `options/gen/` is regenerated alongside those four and is not a supported extension surface. Unconfirmed: kept in full because `generateOptions` emits the whole modules, not because every descriptor is used.
